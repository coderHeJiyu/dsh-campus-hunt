# 安全声明 — dsh-campus-hunt

> 本文是 [README 安全声明节](../README.md)的全文，适用于本插件的 host 工具、runtime skill（采集工作流指令）、GUI 卡片与数据层。

## 1. 采集范围（域名白名单）

- 只采集 `allowedDomains` 白名单内的页面，匹配方式为 host 后缀匹配
  （例如 `nowcoder.com` 覆盖 `www.nowcoder.com`）。
- 白名单默认值为 `nowcoder.com`（牛客），即 v0.1 唯一支持的渠道。
- URL 不在白名单内的条目，由各工具在执行时强制处理（工具本身不做网络 I/O）：
  - `campus_job_search`：跳过该条、不入库，并在返回中报告跳过条数
    （`rejectedDomains`，> 0 时才出现）；
  - `campus_job_detail`：直接错误返回（提示模型），不入库；
  - `campus_schedule`：条目带 URL 时校验，不带 URL 时放行。
- 白名单可在 GUI 设置页卡片中增删域名；改动自下次工具运行起生效
  （设置分节按 restart 语义生效，工具执行时读取当前配置）。

## 2. 只读承诺

- 本插件只做只读采集：岗位列表、JD 详情、校招日程（JD 详情页无需登录可见）。
- 不自动投递：不点「投递」按钮、不填表单、不发消息、不注册账号。
- 需要登录才能完成的操作（如投递），插件输出人工步骤 + 直达链接，由用户
  自己决定是否执行。
- 浏览器由 agent 经 dsh-ego-browser 驱动；插件的 host 工具自身不做网络 I/O。

## 3. 不绕过登录 / CAPTCHA

- 页面出现登录弹窗（牛客的 `.v-modal` / `.login-dialog` 遮罩）时：只按
  Escape 关闭，并记录该事实；不登录、不填任何账号信息。
- 出现登录墙或验证码阻断内容时：立即停止，把现状告知用户，不重试、
  不尝试绕过。
- 采集只取第一屏（专场页约 40 张卡，日程页同理）：不翻页、不点
  「加载更多」、不滚动触发加载。

## 4. 绝不索要凭证

- 本插件绝不向用户索要账号、密码、cookie、token 或任何凭证（与 DSH 的
  secrets ban 一致）。
- 不存储任何凭证：3 个数据文件中只含岗位 / 追踪 / 日程数据；求职画像只存
  设置分节（无 workspace 副本、不产生文件）。

## 5. 频率红线（只收紧、不放松）

| 红线 | 默认值 | 设置页可改范围 | 语义 |
|---|---|---|---|
| 单次采集条数 `maxItemsPerRun` | 50 | 1–50 | 返回数组超过 N 条时只入库前 N 条，并报告截断数（`truncated`，> 0 才出现） |
| 页面导航间隔 `minIntervalMs` | 1000 ms（1 秒） | 1000–600000 ms（1 秒–10 分钟） | agent 在页面导航之间至少等待 N 毫秒 |
| JD 详情采集 | 一次 1 条 | 不可调 | 用户指定采哪条，不批量循环 |

- 设置页只能把红线改得更严格，不能放松（导航间隔下限固定 1 秒，单次条数
  上限固定 50）。
- 这些红线写进 runtime skill 的文案（按当前配置构建）；工具侧的截断 / 跳过
  自下次运行起生效。

## 6. 本地优先：数据不出 workspace

- 3 个数据文件（`jobs.json` / `track.json` / `schedule.json`）全部写入当前
  会话 workspace 根（即对话所在的 workspace），不写固定个人目录、无云服务、
  无网络上传；求职画像不产生文件（只存设置分节，经 `campus_job_search`
  返回的画像行直供模型）。
- 除这 3 个数据文件外，插件不读写用户的其他本地文件。设置中记录的简历文件
  路径（`resumePath`）仅存路径字符串：v0.1 不解析、不读取、不上传简历
  文件本身。
- 数据文件结构、schema 版本与备份约定见
  [workspace 数据文件说明](./workspace-output.zh.md)。

## 7. 声明边界

- 以上为 v0.1 的默认行为。用户通过设置页收紧白名单或频率红线后，行为只
  更严格；「不投递 / 不绕过 / 不索要凭证 / 数据不出 workspace」为硬约束，
  不受设置影响。
- 如发现任何与本声明不符的行为，请向维护者报告（bug 而非特性）。
